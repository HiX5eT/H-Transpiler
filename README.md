# H-Transpiler 🚀

> Haskell tabanlı web sunucusu ve Gemini API desteğiyle çalışan modern kod çevirici (transpiler) uygulaması.

H-Transpiler; kaynak kodlarını dilediğiniz hedef programlama diline güvenli, hızlı ve şık bir arayüz üzerinden dönüştürmenizi sağlayan açık kaynaklı bir projedir.

---

## 🛠️ Kullanılan Teknolojiler

* **Backend:** Haskell (`Scotty` web framework)
* **Frontend:** HTML5, Tailwind CSS (Modern ve koyu tema arayüz)
* **Yapay Zeka:** Google Gemini API
* **Ortam:** GitHub Codespaces / Cabal

---

## 🌟 Öne Çıkan Özellikler

* **Çift Kutulu Modern Arayüz:** Kaynak kodunuzu ve çevrilmiş halini yan yana, okunabilir bir yapıda görmenizi sağlar.
* **Çok Satırlı Kod Desteği:** Sadece tek satır değil, uzun ve karmaşık fonksiyonları/kod bloklarını rahatça çevirebilirsiniz.
* **Haskell Güvencesi:** Arka planda Scotty ile çalışan hafif ve hızlı bir web sunucusu barındırır.
* **Anlık API Entegrasyonu:** Tarayıcı üzerinden doğrudan Gemini API ile haberleşerek hızlı sonuçlar üretir.

---

## 🚀 Projeyi Çalıştırma

Projeyi kendi bilgisayarınızda veya Codespaces ortamında çalıştırmak için şu adımları izleyin:

1. Depoyu klonlayın:
   ```bash
   git clone [https://github.com/HiX5eT/H-Transpiler.git](https://github.com/HiX5eT/H-Transpiler.git)
   cd H-Transpiler
   ````
2. Haskell bağımlılıklarını yükleyip sunucuyu başlatın:
   `````bash
   cabal run
   `````
3. Terminalde belirtilen adrese (varsayılan: http://localhost:3000) tarayıcınızdan gidin!
   
   👨‍💻 Geliştirici:
   **HıX5eT** tarafından geliştirilmiştir.
